# NEXORA — Professional Business Website

A modern responsive business website built with plain HTML, CSS, and JavaScript.

## Project

NEXORA is a fictional technology and digital transformation company.

The website demonstrates a professional business-world layout with:

- Responsive design
- Hero section
- Business services
- Performance metrics
- Case study
- Company principles
- Industry information
- Insights section
- Contact form
- Mobile navigation
- Scroll animations
- Animated statistics

## Files

### `index.html`

Contains the structure and content of the website.

### `style.css`

Contains the complete visual design, layout, responsive behavior, and animations.

### `script.js`

Handles:

- Mobile navigation
- Scroll reveal animations
- Animated statistics
- Contact form interaction

## Running the website

No framework or build system is required.

Simply open:

`index.html`

in a web browser.
